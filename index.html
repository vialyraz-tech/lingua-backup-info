Lingua player Back up

Личный инструмент для автоматического резервного копирования собственного проекта Lingua Player с GitHub на Google Диск.

Как работает резервное копирование

GitHub Actions по расписанию создаёт архив репозитория с Git-историей и загружает его через rclone в папку, указанную владельцем. Автоматизация выполняется на серверах GitHub.

Доступ к Google Диску

Для подключения используется отдельный Google-аккаунт для резервных копий. Владелец основного аккаунта предоставляет ему доступ на редактирование папки бэкапов. Другие личные файлы основного аккаунта, которые не были ему открыты, остаются недоступны.

OAuth-разрешение относится к дополнительному аккаунту и может охватывать доступные ему файлы. Указание папки в настройках rclone задаёт место сохранения; оно само по себе не ограничивает OAuth-разрешение одной папкой.

Назначение

Инструмент предназначен для личного использования владельцем проекта. Он не предоставляет публичную регистрацию и не собирает данные пользователей мобильного приложения Lingua Player.
