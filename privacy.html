Политика конфиденциальности

Эта страница относится к личной автоматизации Lingua player Back up, которая сохраняет резервные копии собственного репозитория Lingua Player с GitHub на Google Диск. Она не является политикой обработки данных мобильного приложения Lingua Player.

Какие данные используются

Автоматизация обрабатывает содержимое выбранного репозитория и его Git-историю, создаваемые архивы, имена и идентификаторы файлов и папок назначения, размеры файлов и сведения о выполнении резервного копирования. Для доступа к Google Drive API используется OAuth-токен дополнительного Google-аккаунта владельца.

Зачем нужен доступ

Доступ применяется для загрузки, проверки и перечисления резервных копий в настроенной папке, а также для удаления старых копий по правилам хранения владельца. Подключение выполняется под дополнительным аккаунтом. Его доступ к основному Диску определяется тем, какие файлы и папки основной аккаунт открыл ему через настройки общего доступа.

OAuth-разрешение может охватывать все файлы, доступные дополнительному аккаунту. Рабочая папка rclone является настройкой назначения, а не самостоятельной границей OAuth-доступа.

Где обрабатываются и хранятся данные

Архив создаётся во временной среде GitHub Actions и передаётся в Google Drive. Учётные данные подключения должны храниться в GitHub Actions Secrets и передаваться процессу резервирования при запуске. Их не следует размещать в публичном репозитории, на этом сайте или в журналах выполнения.

Технические сведения о запусках могут оставаться в журналах GitHub Actions. Обработка данных на инфраструктуре GitHub и Google также регулируется правилами этих провайдеров.

Передача и использование данных

Данные используются для личного резервного копирования. Автоматизация не предназначена для продажи данных, рекламы, передачи рекламным сетям или обучения моделей машинного обучения. GitHub и Google участвуют как провайдеры вычислений и хранения.

Хранение и удаление

Срок и количество сохраняемых копий задаёт владелец. Планируемое правило — последние 30 успешных копий с очисткой более старых только после проверки новой. Владелец может удалить архивы на Google Диске, отключить workflow в GitHub Actions и отозвать OAuth-доступ в настройках Google-аккаунта. Отзыв доступа не удаляет уже созданные архивы.

Этот информационный сайт

Страницы не содержат форм ввода, рекламных скриптов или аналитики приложения. Сайт размещён на GitHub Pages; инфраструктура хостинга может обрабатывать технические данные запросов согласно правилам GitHub.

Контакт

Вопросы можно направить через Issues информационного репозитория. Не включайте в публичные обращения токены, пароли, ключи или содержимое приватных архивов.
